# Подписанные ссылки

## 1. Суть

Выдать URL, который сам несёт свою авторизацию, — чтобы отдать его тому, кто ничего не знает об
учётных данных: браузеру, стороннему сервису, `curl` в чужом скрипте. Работает и на чтение, и на
запись.

Presign ничего не отправляет. Это чистая функция, поэтому она работает **на всех таргетах KMP**,
включая те, где HTTP-движка для нас нет: бэкенд на Kotlin/Native выдаёт ссылку, фронтенд на wasm
её показывает.

## 2. Бизнес-ограничения

- Срок жизни — не больше **7 суток** (604 800 секунд), по умолчанию час. Превышение отвергается
  до отправки; проверить ссылку некому, пока по ней не пойдут.
- Тело неизвестно на момент подписи, поэтому подписывается `UNSIGNED-PAYLOAD`, и `x-amz-content-sha256`
  в ссылке не появляется.
- Подписывается только `host`: браузер, идущий по ссылке, других заголовков не пошлёт.
- `X-Amz-Signature` дописывается последним и в подпись не входит.
- Ключ с сегментом `.` или `..` отвергается: браузер уберёт такой сегмент из пути так же, как
  libcurl.

## 5. Сценарии

| Сценарий | Ожидание | Где проверено |
|---|---|---|
| Семь ссылок против эталонной реализации | совпадают целиком, а не только подписью | `S3SignerVectorTest`, `builds every presigned url` |
| Ссылка на чтение | отдаёт объект обычным HTTP-клиентом | `S3ClientE2eTest`, `serves an object through a presigned get` |
| Ссылка на запись | объект появляется в бакете | `S3ClientE2eTest`, через `Fixture.upload` |
| Подпись испорчена | `403 SignatureDoesNotMatch` с разбираемым телом | `S3ClientE2eTest`, `returns a diagnosable error when a signature is tampered with` |
| Срок больше 7 суток | отказ до отправки | `S3SignerRulesTest`, `presigns for at most seven days` |
